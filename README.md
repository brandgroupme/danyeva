# Мини-сайт Евгении Даныевой

Личный сайт-витрина для закрепа в Telegram: практические консультации, AI-продукты, сайты, маркетинговые проекты, лекции-практикумы и отдельные образовательные проекты.

## Локальный запуск

```powershell
pnpm install
pnpm dev
```

Откройте `http://localhost:3000/`.

## Проверка перед публикацией

```powershell
pnpm build
```
